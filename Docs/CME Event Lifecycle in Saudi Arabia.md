## **EXECUTIVE SUMMARY**

The Continuing Medical Education (CME) event ecosystem in Saudi Arabia operates through a structured but largely **manual and fragmented system** regulated by the Saudi Commission for Health Specialties (SCFHS). The lifecycle spans from event ideation by organizers through accreditation approval, event execution, certificate issuance, and practitioner hour tracking on the Mumaris Plus platform.

**Key findings:**

- **21+ day minimum** lead time required for event accreditation
- **Multiple manual touchpoints** create delays and errors
- **Fragmented systems** between organizers, SCFHS, and practitioners
- **30-day payment windows** with automatic cancellation penalties
- **21-day window** post-event for CME hour registration
- **Significant digitalization gaps** across all stakeholder workflows

## **1. LIFECYCLE STAGES: DETAILED PROCESS FLOW**

### **Phase 1: Event Ideation and Planning (Pre-Application)**

**Duration:** Variable (typically 3-6 months before event)

**Activities:**

- Organizer identifies educational gap or professional development need
- Conceptualizes event format (conference, workshop, webinar, internal lecture series)
- Secures speakers, venue, budget
- Drafts preliminary scientific program
- For **conferences**: Must submit initial reservation **3 months before** event date to reserve calendar slot

**Dependencies:**

- Must avoid date conflicts with similar specialty events (30-day spacing requirement)
- Must have accredited CPD Provider status before applying for activity accreditation

***

### **Phase 2: CPD Provider Accreditation (If Not Already Accredited)**

**Duration:** 60-90 days (first-time providers)

**Process Steps:**

**Step 1: Registration** (Day 1-3)

- Provider Director registers on CPD Platform (https://portal.scfhs.org.sa)
- Verification via National Information Center
- Email verification and account activation

**Step 2: Provider Accreditation Application** (Day 3-10)

- **Six-step process:**

1. Provider Information (establishment verification via Ministry of Interior No. or CR No.)
2. Add Coordinators (with assigned permissions)
3. Scientific Committee details (Chair must be health practitioner with classification number)
4. **20 Mandatory Standards:**
        - Eligibility criteria (training certificates)
        - Professional ethics acknowledgments
        - Regulatory criteria (vision, mission documents)
        - Training process management documentation
5. Review all information
6. Payment of application examination fees

**Step 3: Review and Payment** (Day 10-40)

- Submit application to SCFHS
- **Payment deadline: 30 days** (auto-cancellation if missed)
- SCFHS review process (up to 30 working days)
- Possible status: Under Review, Returned for Editing, Accredited, Declined, Cancelled

**Step 4: Accreditation** (Day 40-90)

- Accreditation fees payment (if approved)
- Download accreditation certificate
- Provider can now apply for activity accreditation

**Required Documents:**

- CVs (Provider Director, Coordinators, Scientific Committee members)
- Training certificates (minimum 2)
- Vision/mission statements
- Quality assurance documents
- Regulatory acknowledgments (signed)

***

### **Phase 3: Activity Accreditation Application**

**Duration:** 21+ days minimum before event

**Timeline Requirements:**

- **Regular/New Activities:** 21 working days before event start
- **Conferences:** Initial reservation 3 months before; full application 21 days before
- **Internal Activities:** 21 days before first lecture
- **E-Learning:** 21 days before module launch

**Application Process (7 Steps for New Activity):**

**Step 1: Activity Information**

- Event title (Arabic \& English)
- Start/end dates
- Location/venue
- Expected participants (number)
- Activity type (workshop, conference, webinar, etc.)
- Attach activity approval letter from organization

**Step 2: Organizational/Regulatory Information**

- Collaborating organizations (if any)
- Scientific Committee Chair verification (by classification number in Mumaris Plus)
- Disclosure agreements

**Step 3: Educational Component**

- Target audience selection (doctors, nurses, pharmacists, technicians, etc.)
- Educational objectives (SMART format required)
- Learning outcomes
- Teaching methodology

**Step 4: Speakers**

- Add all speakers with CVs (optional but recommended)
- Speaker credentials and qualifications

**Step 5: Scientific Program**

- Session-by-session breakdown
- Topics, durations, CME hours per session
- Speaker assignments
- **Total CME hours calculated automatically**

**Step 6: Review**

- Comprehensive review of all entered data
- Submit application (locked after submission)

**Step 7: Payment**

- SADAD payment for application review fees
- **30-day payment window** (application cancelled if not paid)

**Application Review:**

- SCFHS reviews within 10-21 working days
- Possible outcomes: Approved, Returned for Modification, Declined
- If approved: Accreditation certificate issued with unique accreditation number

**Special Case: Recurring Activities**

- Simplified process: Enter previous accreditation number
- Update only dates and location
- Faster approval (typically 7-10 days)

***

### **Phase 4: Marketing and Registration**

**Duration:** Variable (typically 1-3 months before event)

**Current State:**

- **Fragmented approach:** Each organizer uses independent systems
- Marketing channels: CME-KSA.com, ANAT.sa, institutional websites, social media
- Registration: Separate platforms (often spreadsheet-based or basic online forms)
- Payment collection: Bank transfers, online gateways (not integrated with SCFHS)

**Practitioner Experience:**

- Search for events across multiple websites
- Register through organizer's system
- No centralized CME event calendar
- Limited visibility into accreditation status until arrival

***

### **Phase 5: Event Execution and Attendance Verification**

**Duration:** Event day(s)

**Current Attendance Tracking Methods:**

- **Paper sign-in sheets** (most common)
- Excel-based attendance lists
- QR code scanning (rare, advanced organizers only)
- Manual verification of practitioner classification numbers

**Critical Requirements:**

- Verify each attendee is registered in Mumaris Plus with valid classification
- Ensure attendee specialty matches target audience
- Cannot register same practitioner twice for same activity
- Cannot register on dates overlapping with other CME activities (except conference side-events)
- Must not exceed expected participant count declared in application

**Challenges:**

- Long registration queues at event entrance
- Manual data entry prone to errors (typos in names, classification numbers)
- No real-time verification against Mumaris Plus database
- Physical attendance sheets subject to loss or damage

***

### **Phase 6: CME Credit Calculation and Certificate Issuance**

**Duration:** Immediately post-event to 21 days after

**Process:**

**Organizer Responsibilities:**

- **Registration window:** From day after event ends, up to **21 working days maximum**
- Access CPD Platform → Accredited Activities → Select event → CME Hours Registration

**Two Registration Methods:**

**Method 1: Excel File Upload**

- Download template from CPD Platform
- Enter practitioner registration numbers and professional classification numbers
- Upload to system
- System automatically validates against Mumaris Plus database

**Method 2: Manual Entry**

- Enter each practitioner individually
- Real-time validation per entry

**System Sorting:**
After upload/entry, practitioners sorted into three categories:

1. **Approved Registrations** – Valid, successfully registered
2. **Declined Registrations** – With specific rejection reasons (e.g., wrong specialty, duplicate, date conflict)
3. **Incorrect Registration Numbers** – Not found in Mumaris Plus

**Coordinator Actions:**

- Review declined/incorrect entries
- Correct errors and resubmit
- Export lists for record-keeping

**Extension Requests:**

- If 21-day window missed: Can request extension (valid reason required)
- SCFHS reviews extension requests (3-day extension if approved)
- **Only one extension allowed per activity**
- **Cannot request extension after 90 days post-event**

**Certificate Generation:**

- Organizer issues participation certificates (paper or PDF)
- Certificate includes: Event name, date, CME hours, SCFHS accreditation number
- Practitioner receives certificate at event or via email (delays common)

***

### **Phase 7: Practitioner Hour Tracking and License Renewal**

**Mumaris Plus System:**

- CME hours automatically posted to practitioner's Mumaris Plus account after organizer registration
- **Posting timeline:** Typically 20 working days after event (per SCFHS SLA)
- Practitioners log in to Mumaris Plus to view accumulated hours

**Annual Requirements:**

- **General Practitioners/Dentists:** Minimum 30 CME hours/year
- **Specialists:** Minimum 40 CME hours/year
- Requirements vary by license renewal period (1, 3, or 5 years)
- Up to **50% of hours** can be online/asynchronous learning

**Practitioner Challenges:**

- **Certificate delays:** Often weeks or months after event
- **Hour posting delays:** Can take 30+ days for hours to appear in Mumaris Plus
- **No real-time tracking:** Cannot verify hours immediately after event
- **Manual record-keeping:** Must save physical/PDF certificates as backup
- **Uncertainty:** Unclear if hours will count toward renewal until posted
- **Specialty matching:** Hours must align with practitioner's registered specialty

## **4. PAIN POINTS AND PROCESS CHALLENGES**

### **A. Organizer Challenges**

**1. Long Accreditation Lead Times**

- **Issue:** 21-day minimum requirement forces early planning, limiting flexibility
- **Impact:** Cannot respond quickly to emerging clinical topics or urgent training needs
- **Specific Pain:** If application returned for edits, timeline extends further

**2. Manual Application Process**

- **Issue:** Extensive form-filling, document uploads, no autosave
- **Impact:** Risk of data loss, time-consuming (3-5 hours for complex conferences)
- **Quote:** "Organizers spend hours reconciling data between systems" (Samaaro CME study)

**3. Strict Payment Deadlines**

- **Issue:** 30-day payment window with auto-cancellation penalty
- **Impact:** Budget approval delays can result in application cancellation, requiring re-submission
- **Specific Pain:** Fiscal year constraints in public hospitals can cause missed deadlines

**4. Fragmented Systems**

- **Issue:** CPD Platform only handles accreditation; organizers must use separate tools for marketing, registration, payment
- **Impact:** No single source of truth; data re-entry across platforms
- **Example:** Attendance list created in Excel → manually uploaded to CPD Platform → hours manually posted to Mumaris Plus

**5. Post-Event Administrative Burden**

- **Issue:** CME hour registration within 21 days requires manual data validation
- **Impact:** Coordinator workload spikes after large events (conferences with 500+ attendees)
- **Error Risk:** Typos in practitioner classification numbers cause registration failures

**6. Certificate Generation and Distribution**

- **Issue:** No automated certificate system; organizers create manually
- **Impact:** Delays of weeks or months; practitioners chase certificates
- **Complaint:** "Certificates were delayed for weeks after CME events" (CME event management study)

**7. Limited Communication with SCFHS**

- **Issue:** No real-time status updates; coordinators must log into platform to check
- **Impact:** Uncertainty about approval status; missed deadlines

## **6. BENCHMARKS AND GLOBAL COMPARISONS**

### **United States (ACCME System)**

**Accreditation Model:**

- Accreditation Council for Continuing Medical Education (ACCME) oversees accreditation
- **Joint Accreditation:** Single accreditation for interprofessional CME (physicians, nurses, pharmacists)
- **Commendation Criteria:** High-performing providers receive extended accreditation terms (up to 6 years)

**Digital Integration:**

- **CE Broker:** Many states use CE Broker for automated license renewal tracking
- **PARS (Physicians' Achievement \& Recognition System):** AMA's platform tracks CME credits, integrates with employer systems
- **Commercial Platforms:** Medscape, UpToDate, CMEList offer searchable CME directories

**Best Practices:**

- **Pre-approval exemptions:** Accredited providers can offer CME without per-activity approval (trust-based model)
- **Mobile-first:** Most platforms have robust mobile apps
- **Instant certificates:** Digital certificates issued immediately post-activity

**Lessons for Saudi Arabia:**

- **Trust-based accreditation:** Consider pre-approval for high-performing providers (reduces SCFHS workload)
- **Joint accreditation:** Explore interprofessional CME to streamline process
- **Ecosystem integration:** Mandate API access for all CME platforms

***

### **United Kingdom (CPD System)**

**Accreditation Model:**

- General Medical Council (GMC) oversees CPD for physicians
- **Self-directed learning emphasis:** Practitioners identify own learning needs, create annual CPD plan
- **Reflective practice required:** Must demonstrate how learning improved practice

**Digital Tools:**

- **CPD Diary:** Digital portfolio for recording learning activities
- **Royal Colleges' platforms:** Specialty-specific CPD tracking (e.g., RCP, RCGP)
- **Integration with revalidation:** CPD records feed directly into 5-year revalidation process

**Best Practices:**

- **Flexible hour requirements:** No rigid minimum; focus on quality and relevance
- **Digital portfolio:** Lifetime learning record, accessible anytime
- **Reflective practice:** Ensures learning translates to patient care improvement

**Lessons for Saudi Arabia:**

- **Digital portfolio:** Implement cloud-based CME certificate storage for practitioners
- **Reflective practice:** Consider requiring practitioners to document how CME improved practice (quality over quantity)

***

### **United Arab Emirates (DHA Dubai)**

**Accreditation Model:**

- Dubai Health Authority (DHA) oversees CME for Dubai-based practitioners
- **CME credit requirements:** 40 credits/year for physicians (similar to Saudi Arabia)
- **Category breakdown:** Credits divided into Category 1 (external courses) and Category 2 (self-learning)

**Digital Integration:**

- **Sheryan Platform:** DHA's digital licensing and CME tracking system
- **Automatic credit posting:** Many accredited providers have direct integration with Sheryan
- **Mobile app:** Practitioners can check credits, register for events via app

**Best Practices:**

- **Provider integration:** DHA mandates API integration for high-volume CME providers
- **Real-time verification:** Practitioners receive SMS confirmation when credits post
- **Category flexibility:** Self-directed learning counts toward total (encourages diverse learning methods)

**Lessons for Saudi Arabia:**

- **Mandatory integration:** Require large CME providers to integrate with Mumaris Plus via API
- **SMS confirmations:** Instant notification to practitioners when hours post
- **Self-learning category:** Recognize journal reading, online modules (beyond formal events)

***

### **Singapore (SMC System)**

**Accreditation Model:**

- Singapore Medical Council (SMC) oversees CME
- **Points system:** 50 CME points per 2-year cycle (1 hour = 1 point)
- **Core vs. non-core:** Minimum core points required (clinical topics); non-core includes soft skills

**Digital Tools:**

- **CME Portal:** Centralized event calendar and registration
- **Integrated credit tracking:** Automatic posting from accredited providers
- **Audit functionality:** SMC can randomly audit practitioner CME records

**Best Practices:**

- **Core/non-core split:** Ensures clinical competency while allowing professional development breadth
- **Audit system:** Random checks ensure compliance, reduce fraud
- **Centralized portal:** Single source of truth for all CME activities

**Lessons for Saudi Arabia:**

- **Core/non-core categories:** Consider specialty-specific core requirements + flexible electives
- **Audit mechanism:** Random CME record audits to ensure integrity
- **Single portal:** Unified platform for discovery, registration, and tracking (as proposed above)

## **CONCLUSION AND RECOMMENDATIONS**

### **Key Takeaways**

1. **Current System is Functional but Fragmented:** SCFHS has established clear processes via CPD Platform and Mumaris Plus, but lack of integration creates inefficiencies, delays, and practitioner frustration.
2. **Manual Touchpoints are the Primary Bottleneck:** From application review to hour registration to certificate issuance, manual processes cause delays and errors across the lifecycle.
3. **Practitioner Experience Suffers:** 20-30+ day wait for CME hours to post, certificate delays, and fragmented event discovery create anxiety and administrative burden.
4. **Organizers Bear Heavy Administrative Load:** Post-event hour registration for large conferences (500+ attendees) is time-consuming and error-prone with current tools.
5. **Global Best Practices Show the Way:** API integration, real-time hour posting, mobile apps, and centralized calendars are standard in advanced CME ecosystems (USA, UAE, Singapore).

***

### **Strategic Recommendations**

**For SCFHS:**

1. **Prioritize API Development:** Open Mumaris Plus and CPD Platform APIs to enable ecosystem integration.
2. **Launch Pilot Integration:** Partner with 5 high-volume organizers (e.g., KSAU-HS, King Faisal Hospital, Saudi Heart Association) for QR-based real-time hour posting.
3. **Mandate Mobile-First Design:** Redesign Mumaris Plus and CPD Platform with mobile UX as priority.
4. **Establish Audit Function:** Random audits of organizer-submitted CME hours to ensure compliance and detect fraud.
5. **Create Fast-Track Program:** Reward high-performing providers with expedited approval processes.

**For Organizers:**

1. **Invest in Digital Infrastructure:** Transition from paper attendance to QR-based systems (low-cost pilot with 1-2 events).
2. **Adopt Event Management Platforms:** Use integrated CME platforms (e.g., Samaaro, BeaconLive) instead of spreadsheets.
3. **Collaborate on Standards:** Work with SCFHS to define API specifications for hour submission.
4. **Automate Certificates:** Use templating systems for instant digital certificate generation post-event.

**For Practitioners:**

1. **Demand Transparency:** Advocate for real-time hour posting and instant certificate access through professional associations.
2. **Adopt Digital Tools:** Use available platforms (CME Hours, TebZone) for searchable event discovery.
3. **Maintain Backup Records:** Continue saving certificates until Mumaris Plus integration matures.

This transformation will position Saudi Arabia as a **regional leader in digital health education**, improve practitioner satisfaction, reduce administrative burden, and ultimately enhance patient care through more accessible, high-quality continuing education.
