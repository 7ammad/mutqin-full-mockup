## Usage Guidelines

### Primary Colors
- **Apple Blue**: Primary buttons, links, active states, focus rings
- **Apple Green**: Success messages, completed states, CME hours, health indicators
- **Apple Red**: Error messages, destructive actions, warnings
- **Apple Orange**: Pending states, warnings, attention needed

### Semantic Colors
- **Always use semantic names** (`--label`, `--system-background`) instead of hardcoded colors
- **Automatic adaptation**: Semantic colors adapt to light/dark mode automatically
- **Accessibility**: All color combinations meet WCAG AA contrast requirements

### CSS Variable Usage

```css
/* System Colors */
color: var(--apple-blue);
background: var(--apple-green);

/* Semantic Colors */
color: var(--label);
background: var(--system-background);
border: var(--separator);
```

### TypeScript Usage

```typescript
import { cssVariableNames } from '@/lib/apple-colors';

// Use CSS variables
const primaryColor = cssVariableNames.systemBlue; // "--apple-blue"
```

## Color Conversion Notes

**OKLCH to Hex Approximations:**
- OKLCH values are perceptual and may not map exactly to hex
- Hex values shown are approximations for reference
- **Always use CSS variables** (`var(--apple-blue)`) in code, not hex values
- OKLCH provides better color consistency across devices and themes

**Why OKLCH?**
- Perceptual uniformity (equal steps = equal perceived difference)
- Better color consistency across displays
- Automatic light/dark mode adaptation
- Apple's recommended color space for modern design systems
